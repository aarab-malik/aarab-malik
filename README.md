## About Me

Data science student based in **Islamabad**, building practical software at the intersection of AI, data, and full-stack engineering.

- Developing AI-powered applications with Python, TypeScript, and modern web tooling
- Interested in retrieval systems, AI agents, intelligent search, and grounded user experiences
- Building full-stack products from backend APIs and data models to polished frontend workflows
- Comfortable working across application development, automation, and algorithmic problem solving
- Open to collaboration, internships, and opportunities in AI/ML engineering

## What I’ve Been Building

### AI-powered knowledge tools

I’ve been working on applications that turn unstructured technical notes into searchable, structured knowledge. This includes building interfaces and APIs, account-aware data flows, semantic retrieval, source-grounded answers, and integrations with hosted databases and model providers.

### Full-stack applications

I build end-to-end products with React/Next.js and TypeScript on the frontend, alongside Python APIs, PostgreSQL-backed data models, authentication, and deployment-oriented configuration.

### Intelligent game systems

I’ve also explored adversarial search through configurable game agents, implementing Minimax and Expectimax strategies with JavaScript and Node.js.
